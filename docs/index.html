Welcome

A native chatbot client and coding agent for Windows XP. GxPT brings agentic workflows to the era of Luna and Aero — autonomously chaining tools for agentic coding and web search via the Model Context Protocol (MCP), with per-conversation privacy controls.

Features

  • Agentic Workflows — autonomously chains tool calls until your task is done: agentic coding (file/git/shell), web search & fetch, and GitHub access via MCP.
  • Skills — teach GxPT reusable workflows that bundle instructions and optional scripts; author your own with the built-in skill-writer.
  • Sub-Agents — delegate self-contained tasks to specialist agents that work in an isolated context and report back only their final answer, keeping the main conversation lean.
  • Plugins — bundle skills and agents into a single shareable .gxpl plugin you can install, upgrade, enable/disable, and uninstall by name.
  • Interactive Questions — when the model needs a decision, it can ask a multiple-choice (or multi-select) question right in the transcript; pick an option, check several, or type your own answer.
  • Graphviz Diagrams — your agent can send flowcharts, call graphs, class diagrams, and more right in the chat; click a graph to open it in a pan/zoom viewer.
  • Persistent Memory — records durable facts about each workspace and recalls them in later conversations, so context carries over.
  • AGENTS.md Support — project instructions in your workspace root's AGENTS.md are injected into the agent's system prompt automatically.
  • Prompt Caching — requests are zoned for provider prompt caches, with sticky routing that keeps follow-ups on the warm cache — up to ~90% off input costs on long agentic sessions.
  • Usage Status Bar — a live context meter plus running cost and cache-savings totals for every conversation.
  • Tool Approval & Sandboxing — every tool call is gated by an in-app approval prompt; command approvals add an Explain button that asks the model to break down what a pending command does. File/git/command tools stay confined to the workspace you choose.
  • Slash Commands — quick / actions with autocomplete: /model, /toggle-tool, /new-conversation, /export, /plugin, and /compact.
  • Markdown & Syntax Highlighting — rich Markdown rendering plus code highlighting for 50+ languages.
  • File Attachments — attach text files, images, and PDFs; images go to vision-capable models, and PDFs use fast local text extraction with full-document escalation where supported.
  • Privacy & Local Storage — conversations stored locally; enforce Zero Data Retention (ZDR) per conversation.
  • Frontier Model Support — a huge range of AI models through the OpenRouter.ai API.
  • Legacy Compatibility — runs on Windows XP and .NET 3.5.
